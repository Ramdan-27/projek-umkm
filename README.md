☕ Kopi Jalanan - UMKM Coffee Street Platform

"Seduh Cita Rasa Bintang Lima di Pinggir Jalan"

Platform web interaktif all-in-one yang dirancang untuk mendukung Usaha Mikro, Kecil, dan Menengah (UMKM) kedai kopi jalanan dalam mendigitalisasi pemesanan langsung, manajemen inventaris menu, pelacakan kasir real-time, serta integrasi pemesanan online via GoFood.

🚀 Fitur Utama (Core Features)

🛒 1. Sisi Pelanggan (Customer View)

Katalog Menu Dinamis & Kategori Filter: Cari dan filter menu berdasarkan Kopi Espresso, Non-Kopi, dan Makanan Ringan/Snack dengan fitur pencarian instan.

Keranjang Pesanan Interaktif (Drawer): Ubah jumlah kuantitas, tambahkan catatan khusus pada pesanan (misal: Less sugar, extra ice), serta pilih opsi Makan di Tempat (Dine-In) atau Bungkus (Takeaway).

Sistem Pembayaran Modern: Simulasi pembayaran digital lengkap termasuk QRIS Auto, GoPay, Transfer Bank (BCA/Mandiri), hingga Bayar Tunai di Kasir.

Struk Digital & Pelacakan Status: Menghasilkan resi pesanan digital interaktif yang lengkap dengan status progres (Diterima ➔ Diseduh ➔ Siap) serta opsi cetak struk/PDF (Print Ready).

Integrasi GoFood Partner: Banner dan modal khusus yang mengarahkan pelanggan langsung ke merchant resmi GoFood dengan promo diskon khusus.

📊 2. Sisi Kasir & Admin (Admin Dashboard)

Dashboard Metrik Keuangan: Pemantauan real-time untuk total pesanan masuk, estimasi omset harian, antrean pesanan aktif, dan jumlah menu aktif toko.

Manajemen Antrean Pesanan: Ubah status pesanan secara live dari proses dapur hingga siap disajikan kepada pelanggan.

Kelola Stok Inventaris Menu: Toggle status ketersediaan barang (Ready / Habis) dan hapus menu dengan cepat.

Modal Tambah Menu Baru: Formulir interaktif untuk mempublikasikan produk kopi atau snack baru langsung ke halaman toko secara instan.

🛠️ Teknologi yang Digunakan

Proyek ini dibangun menggunakan pendekatan Single-File Application yang ringan tanpa memerlukan proses build atau instalasi framework yang rumit:

HTML5 & Semantic Markup

Tailwind CSS (via CDN) untuk styling responsif modern berbasis utility-first.

FontAwesome 6.4.0 untuk ikon visual yang elegan.

Google Fonts (Plus Jakarta Sans & Playfair Display).

Vanilla JavaScript (ES6+) untuk manajemen state aplikasi secara reaktif.

📦 Cara Menjalankan Proyek (Quick Start)

Karena proyek ini menggunakan arsitektur satu berkas (Single-File Mandate), Anda tidak memerlukan Node.js atau dependensi tambahan untuk menjalankannya:

Clone repository ini atau unduh berkas kopi_jalanan_umkm_app.html.

Buka berkas tersebut menggunakan peramban web modern apa pun (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

(Opsional) Ubah nama berkas menjadi index.html jika Anda ingin langsung mendeploynya ke GitHub Pages atau platform hosting statis lainnya.

🖥️ Panduan Penggunaan Singkat

Simulasi Pelanggan: Jelajahi menu, tambahkan kopi favorit ke keranjang, isi data diri, pilih metode pembayaran, dan selesaikan pesanan.

Beralih ke Mode Admin: Klik tombol "Mode Kasir/Admin" di bagian atas navbar untuk melihat antrean pesanan masuk dan mengelola ketersediaan stok menu secara langsung.
